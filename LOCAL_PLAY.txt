WINDOWS LOCAL PLAY
Extract the whole ZIP. Double-click Start_Local_Game.bat. Keep the launcher window open. No Python or Node installation is required.
Use the same launcher/address on later visits to retain progress. Direct file:// HTML opening is unsupported because Edge/Chrome block asset processing.
