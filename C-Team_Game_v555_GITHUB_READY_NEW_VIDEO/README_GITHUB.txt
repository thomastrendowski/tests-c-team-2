THE C-TEAM — GITHUB READY

1. Extract this ZIP.
2. Put your compressed video into Media/Intro_Video and name it intro.mp4 (under 100 MB).
3. Copy the CONTENTS of this folder into your repository folder: index.html, Game, Media, and the other included files.
4. Keep the folder structure intact. Upload the extracted files, not this ZIP.
5. Commit and push using GitHub Desktop.

IMPORTANT: Your earlier commit still contains the oversized files. Deleting or replacing them in a later commit does not remove them from Git history. For this proof of concept, use a fresh repository/clone and copy these files into it. Keep your original game folder as a backup.

For GitHub Pages, index.html is the entry point. Enable Pages for your branch and repository root.
